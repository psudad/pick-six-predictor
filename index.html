How the predictor works

The Pick Six Predictor scores each team using only games from earlier weeks (no peeking at the same week). For each team we combine:

  • 40% — season win percentage so far
  • 35% — average point differential per game (scaled to a 0–1 range)
  • 25% — recent form (win rate in the last 3 games)
  • +0.04 — small home-field bonus applied only to the home team

Whichever side has the higher composite score is the predicted winner. Confidence is higher when the two scores are farther apart (about 52%–92%).

Backtest accuracy on the Accuracy tab uses the same rules for every completed week this season. See README for the full formula.
